# Insert Danger Callout

## Description

Inserts a pre-made danger block at the cursor location, exactly as written, regardless of whether other tabs already exist in the file.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:

:::danger[Optional Your Title **with** some _Markdown_ `syntax`!]

Some **content** with _Markdown_ `syntax`. Check [this `api`](#).

:::
