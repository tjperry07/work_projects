# Insert Button Link

## Description

Inserts a pre-made button link block at the cursor location, exactly as written, regardless of whether other tabs already exist in the file.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:

<ButtonLink to="/docs/build-your-pipeline/advanced-node-functionality">
  Advanced Node Functionality
</ButtonLink>

<ButtonLink to="/downloads/dashboards.csv"> 
  dashboards.csv example file
</ButtonLink>
