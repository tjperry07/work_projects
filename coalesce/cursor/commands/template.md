# Insert Template

## Description

Inserts a pre-made template at the cursor location, exactly as written, regardless of whether other markdown csv blocks already exist in the file.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:

---
title: "Replace with page title. This is your h1. your headings should start at h2"
description: "Write the doc, then ask CHATGPT to create a SEO and AI friendly description"
keywords: [Coalesce internal macros, data transformation macros, Write the doc, then ask CHATGPT to create a SEO and AI friendly keywords in this format]
---

## The first heading is a h2
