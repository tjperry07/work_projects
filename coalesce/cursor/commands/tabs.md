# Insert Tabs

## Description

Inserts a pre-made tabs block at the cursor location, exactly as written, regardless of whether other tabs already exist in the file.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:

<Tabs>
  <TabItem value="apple" label="Apple" default>
    This is an apple 🍎
  </TabItem>
  <TabItem value="orange" label="Orange">
    This is an orange 🍊
  </TabItem>
  <TabItem value="banana" label="Banana">
    This is a banana 🍌
  </TabItem>
</Tabs>
