# Insert Error Table

## Description

Inserts a pre-made danger block at the cursor location, exactly as written, regardless of whether other tabs already exist in the file. The spreadheet id can be found here:
`https://docs.google.com/spreadsheets/d/<1tne4FWXGSG49qKys68qvQ9YjJ7V3oIgRkCJhvUbuAiQ>edit?gid=0#gid=0`

Make sure the table is shared to anyone with a link.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:


<ErrorTable spreadsheetId="sheet-id" />
