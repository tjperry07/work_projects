# Add Summary to Section

## Description

Adds a brief summary or introductory sentence to a section, following Coalesce style.

## Prompt

Add a concise summary or introductory sentence to the selected section. The summary should:

- Be 1–3 sentences
- Give readers a quick overview of what the section covers
- Use plain language and "you" for the reader
- Follow Coalesce voice: friendly, helpful, confident, concise
- Be placed at the start of the section, before the first subheading or list

Output the full section with the new summary inserted at the beginning.
