# Setup the docusarus project

## Node Check

First, check if Node.js is installed on the system. If Node.js is installed, verify that the version is at least 22.20.0. If the installed version is older than 22.20.0, install version 22.20.0 and switch to using it. If Node.js is not installed at all, install version 22.20.0.

## Install the Repo

Finally, install the project dependencies by running npm install in the repository directory.
