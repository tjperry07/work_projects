# Insert Code Block

## Description

Inserts a pre-made code block at the cursor location, exactly as written, regardless of whether other tabs already exist in the file.

## Prompt

Insert this at the cursor location, with no modifications, checks, or extra context:

```jsx title="/src/components/HelloCodeTitle.js"
function HelloCodeTitle(props) {
  return <h1>Hello, {props.name}</h1>;
}
```
